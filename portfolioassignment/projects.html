Report Management System

Report Management System is a web-based application developed using HTML, CSS, PHP, and MySQL. It allows users to create, manage, and generate reports by entering event details, descriptions, and images. The system stores report data in a database and provides an organized way to view, manage, and generate reports in PDF format. It reduces manual work and improves the efficiency of report management.

Scan2Care

Scan2Care Smart Patient Registration and Consent Management System is an application designed to simplify hospital registration and patient consent processes using AI-based document processing. It uses Optical Character Recognition (OCR) to scan and extract information from medical documents, reducing manual data entry and saving time. The system helps healthcare professionals manage patient records efficiently while improving the accuracy and accessibility of medical information.

Bus Buddy

Bus Buddy is a smart bus tracking application designed to help passengers track buses and access real-time transportation information. It provides details about bus locations, routes, schedules, and estimated arrival times. The application helps users plan their journeys efficiently, reduces waiting time, and improves the overall public transportation experience.
